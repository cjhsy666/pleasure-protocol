## 三块拼图

| 拼图 | 作用 | 为什么需要它 |
|------|------|-------------|
| **ESP32 固件** | WiFi → BLE 桥接 | AI 通过网络发送指令，ESP32 转化为蓝牙信号 |
| **Python 脚本** | PC 端 BLE 直连 | 开发调试用，也是 AI 工具调用的底层接口 |
| **LinkZone 插件** | 聊天 → 控制 | AI 通过聊天消息驱动设备，自然语言就是遥控器 |

三者共享同一套协议（`gk36_protocol`），同一个控制逻辑。
选哪个取决于你的 AI 从哪里发出指令。

## 现在能做什么

### ESP32 固件（手机/平板）

```bash
pio run -t upload
# 手机连 WiFi: pleasure-protocol (密码: 12345678)
# 浏览器打开: http://192.168.4.1
```

暗黑主题 Web 面板，滑块控制，实时响应。

### Python 脚本（PC 开发/AI 调用）

```bash
pip install bleak
python scripts/GK36_Controller.py
# s3 = 电击3档
# se50 = 震动50%
# l = 灯光
```

也是 AI 未来调用的底层接口——AI 生成 Python 代码，直接控制设备。

### LinkZone 插件（聊天控制）

```bash
cp -r plugins/gk36/ /你的linkzone/plugins/
# 重启框架
# 群里发: 电击3档 / 震动75 / 开灯
```

AI 通过聊天消息驱动设备，自然语言就是指令。

## 协议破解

> 12 字节，3 个通道，所有秘密。

```
  0x23 0x81 0xBB 0xAB 0xD2 [CH] [EN] [LV] 0xBB 0xA3 0x3B [CK]
  ├── 固定头 (5B) ──────────┤  │    │    │   ├── 校验 (4B) ──┤
                            通道  使能  强度
```

### 电击 (0x4B)

| 档位 | byte6 | byte7 | 体感 |
|------|-------|-------|------|
| 关闭 | `0x43` | `0x23` | — |
| 空闲 | `0x47` | `0x23` | 已就绪 |
| 1 | `0x47` | `0x20` | 轻轻的 |
| 2 | `0x47` | `0x21` | 嗯？ |
| 3 | `0x47` | `0x22` | 有点感觉了 |
| 4 | `0x47` | `0x25` | 开始认真了 |
| 5 | `0x47` | `0x26` | 抓紧了 |
| 6 | `0x47` | `0x27` | 全力以赴 |

### 震动 (0xEC)

100 级，`b6` 字节非线性映射。`0x3B` 停止码。

### 灯光 (0xC8)

两状态交替。亮 / 灭。

## FAQ

**Q: 为什么不直接用官方 App？**
A: 因为 App 不会和你聊天，不会读懂你的情绪，不会根据你的反应调整强度。AI 会。

**Q: AI 控制什么时候能用？**
A: 基础设施已就绪（协议 + 控制层 + 聊天接口）。下一步是接入大模型，让它学会"感知→判断→控制"的闭环。

**Q: 支持其他设备吗？**
A: 目前只针对 GK36。但架构是通用的——换个协议表就能适配其他 BLE 设备。

**Q: 会损坏设备吗？**
A: 不会。我们发送的数据包和官方 App 完全一致。
